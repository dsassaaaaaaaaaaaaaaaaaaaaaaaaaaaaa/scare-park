## Что изменилось в v2

- **01-business.md — полностью переработан:** актуальные ставки DevEx ($0.0038 базовая, $0.0054 для 18+ US), Creator Rewards (Daily Engagement + Audience Expansion), VIP-подписка вместо разового VIP, Nightmare Pass (ранговый пасс), троллинг-магазин, гифтинг, Managed Pricing / Price Optimization, A/B-тест стартового оффера, разделы по Казахстану (вывод денег через Tipalti, налоги по новому НК РК 2026, Astana Hub), юнит-экономика в 4 сценариях и финплан первого года.
- **00-design-doc.md:** обновлены прайс-лист (подписка, Nightmare Pass, троллинг-гаджеты, гифтинг), структура выручки, экономика Robux, роадмап.
- **03-marketing.md:** добавлена монетизация трафика через Audience Expansion (35% от покупок приведённых игроков) и мультиязычная стратегия.
- **07-analytics.md:** добавлены события подписки, гифтинга, троллинг-магазина и «первой игры дня»; расширен еженедельный дашборд.
