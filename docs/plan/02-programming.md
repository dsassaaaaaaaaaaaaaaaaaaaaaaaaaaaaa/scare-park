# 💻 Программирование — инструкция

> 🎯 Цель: сервер-авторитарная архитектура, где клиенту не доверяют никогда. В игре про коллекционирование главная катастрофа — потеря или дюп данных игрока.

# Стек

| Инструмент | Зачем |
| --- | --- |
| Roblox Studio + Luau | основа |
| Rojo + VS Code + Git | код в файлах, версионирование (можно отложить на после MVP) |
| ProfileStore (или ProfileService) | сохранения без дюпов и потерь — стандарт индустрии |
| MemoryStore + TeleportService | матчмейкинг по тирам между серверами |
| MessagingService | глобальные ивенты («в парк X идёт кража!») |

# Архитектура: сервисы (ModuleScripts на сервере)
1. **DataService** — профиль игрока: монстры, валюты, ранг, пасс, престиж. Всё через ProfileStore, автосейв каждые 30–60 сек.
2. **PlotService** — выдача участков, сохранение/загрузка построек (сериализация в таблицу, не хранить инстансы).
3. **FusionService** — таймеры фьюжна считаются от os.time() (не от тиков сервера!) — работают офлайн. Рецепты — таблица на сервере, клиент их не видит.
4. **ScareService** — шкала храбрости, расчёт очков страха. Считает ТОЛЬКО сервер: клиент шлёт только позицию/взгляд, сервер проверяет дистанцию до монстра и кулдауны.
5. **RankService / SeasonService** — очки ранга, rank lock, сезонный сброс по глобальному таймстампу сезона.
6. **ShopService** — ротация магазина: сид = floor(os.time()/300), одинаковая витрина на всех серверах.
7. **MonetizationService** — все покупки через ProcessReceipt, идемпотентно (повторный чек не выдаёт товар дважды), выдача только после успешного сохранения.
8. **AnalyticsService** — лог событий: сессии, фьюжны, покупки, побеги (AnalyticsService Roblox + свои события).

# Порядок работы (по этапам роадмапа)
1. Неделя 1: DataService + PlotService (сохранение — фундамент, делается ПЕРВЫМ).
2. Неделя 2–3: FusionService + ShopService + базовый UI.
3. Неделя 3–4: ScareService + роль посетителя.
4. Неделя 5–6: офлайн-доход, MonetizationService, полиш, закрытый тест.

# 🚫 Правила (жёсткие «нельзя»)
1. Никогда не доверять клиенту: любой RemoteEvent валидируется на сервере (типы, диапазоны, кулдауны, дистанции).
2. Никогда не хранить валюту/инвентарь на клиенте — только отображение.
3. Нельзя выдавать покупку до подтверждённого сохранения — иначе дюп через краш сервера.
4. Нельзя менять схему данных без версии и миграции: в профиле всегда поле dataVersion.
5. Нельзя деплоить в прод без тестового плейса: отдельный плейс с тем же кодом для проверки обновлений.
6. Нельзя держать секреты (рецепты фьюжнов, шансы мутаций) в ReplicatedStorage — только ServerStorage/ServerScriptService.
7. Нельзя игнорировать BindToClose: при выключении сервера — принудительное сохранение всех профилей.

# ✅ Рекомендации
1. Начать с готового референса: на DevForum есть бесплатный «Steal a Brainrot Complete Game Kit + Tutorial Series» — изучить архитектуру, но не копировать вслепую.
2. Все балансовые числа (таймеры, цены, шансы) — в одном конфиг-модуле, а не разбросаны по коду — баланс правится без поиска по проекту.
3. Feature flags: каждая крупная фича включается/выключается флагом — сломалось в проде → выключил без отката.
4. Скримеры и эффекты — на клиенте (плавность), результат (урон храбрости) — на сервере.
5. С первого дня логировать аналитику — через месяц данные будут бесценны, задним числом их не собрать.
6. Тестировать на слабом телефоне еженедельно: основная аудитория — мобилки, десктопный FPS ничего не гарантирует.
7. Анти-чит: лимит скорости запросов на игрока, санити-чек позиций (телепорт-хаки), лог подозрительных событий вместо мгновенного бана.

# Схема данных игрока (эскиз)
```lua
profile = {
  dataVersion = 1,
  coins = 0,          -- основная валюта
  courage = 0,        -- валюта посетителя
  monsters = {        -- { id, rarity, mutation, legendPoints, primeStars }
  },
  plot = {},          -- сериализованные постройки
  rank = { tier = 1, step = 0, points = 0, seasonPeak = 0, lockTier = 0 },
  pass = { xp = 0, premium = false, claimed = {} },
  offers = { firstPurchaseDone = false, ladder = 0 },
  fusion = { slots = {}, finishAt = 0 },  -- os.time()
  stats = { scares = 0, visits = 0, escapes = 0 },
}
```
