# 👥 Комьюнити и LiveOps — инструкция

> 🎯 Цель: игра-сервис живёт ритмом: сезоны — крупный ритм, недельные ивенты — средний, ежедневные поводы зайти — мелкий. Комьюнити — бесплатный отдел QA, маркетинга и гейм-дизайна, если с ним правильно работать.

# Структура Discord
- #анонсы — только админ, коротко, с картинками.
- #клипы — игроки постят испуги; «клип недели» получает внутриигровую награду.
- #баги — шаблон: что делал / что ожидал / что произошло / устройство.
- #идеи — свободный поток + ежемесячное голосование за следующего монстра.
- #тестеры — закрытый канал для активных: ранний доступ к обновлениям на тестовом плейсе.

# LiveOps-календарь

| Ритм | Событие |
| --- | --- |
| Каждые 4 недели | новый сезон: тема, монстры, пасс, мягкий сброс |
| Каждую неделю | мини-ивент: двойные очки страха на выходных, охота на конкретного монстра |
| Несколько раз в день | Blood Moon (шансы мутаций ×2 на 20 минут) — повод зайти «прямо сейчас» |
| К каждому обновлению | код на награду (публикуется в TikTok/Discord — тащит трафик в соцсети) |

# Работа с фидбеком
1. Раз в неделю собирать топ-5 жалоб (Discord + комментарии под игрой).
2. Минимум одна жалоба чинится в ближайшем патче И ПУБЛИЧНО отмечается: «вы просили — мы сделали». Это строит лояльность сильнее любой рекламы.
3. Идеи игроков — фильтровать через вопрос «двигает ли это один из 4 счётчиков?» — если нет, вежливо отклонять.

# Протокол кризиса (дюп-баг, эксплойт, падение)
1. Выключить сломанную фичу feature-флагом (см. ветку Программирование).
2. Короткий честный анонс: что сломалось, что делаем. Без молчания — молчание рождает панику и теории.
3. После фикса — компенсация ВСЕМ (не только пострадавшим), чуть щедрее ущерба — кризис превращается в праздник.
4. Откат экономики — только при массовом дюпе, и с компенсацией честным игрокам.

# 🚫 Правила (жёсткие «нельзя»)
1. Нельзя публично спорить и ругаться с игроками (аудитория — дети; любой конфликт становится контентом против тебя).
2. Нельзя обещать даты и фичи, в которых нет уверенности.
3. Нельзя банить без логов/доказательств и без возможности апелляции.
4. Нельзя игнорировать волну одинаковых жалоб: 10+ сообщений об одном и том же = реальная проблема, даже если «у меня всё работает».
5. Нельзя отдавать модерацию случайным волонтёрам без правил: письменный кодекс модератора до выдачи прав.

# ✅ Рекомендации
1. Коды наград публиковать только в своих каналах (TikTok/Discord/группа) — игра конвертирует игроков в подписчиков.
2. Голосования за контент (следующий монстр, тема сезона) — игроки борются за «своего» кандидата и возвращаются посмотреть на победителя.
3. Активных игроков превращать в тестеров и модераторов — статус бесплатен для тебя и бесценен для них.
4. Вести публичный роадмап без дат («в работе / скоро / думаем») — снижает поток вопросов «когда апдейт?».
5. Первых 100 активных игроков знать поимённо: они — будущие модераторы, тестеры и амбассадоры.
