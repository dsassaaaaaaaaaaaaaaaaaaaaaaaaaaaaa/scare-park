# 🎢 Scare Park — дизайн-документ (Roblox)

> 🎯 **Концепция в одном предложении:** тайкун-парк ужасов, где игроки фьюзят монстров, пугают живых посетителей (других игроков) и соревнуются в сезонной ранговой лестнице «страшности» — fusion-ядро жанра brainrot + удержание по модели Supercell.

# 1. Обзор

| Параметр | Значение |
| --- | --- |
| Платформа | Roblox |
| Жанр | Тайкун + кооп-хоррор + fusion + social |
| Аудитория | 9–16 лет |
| Сессия | 15–40 минут |
| Референсы | Steal a Brainrot (fusion, кража), Grow a Garden (офлайн-прогресс, ротация магазина), Brawl Stars (ранги, сезоны, пропуск, престиж), 99 Nights in the Forest (эскалация ночей) |

**Почему сейчас:** тайкуны и кооп-хоррор — самые быстрорастущие категории Roblox 2026, при этом на пересечении «хоррор + тайкун + fusion» никто не стоит. Эра брейнрот-мемов затухает — игра не привязана к чужому умирающему мему.
**Виральный крючок:** посетители парка — живые игроки. Их испуганные реакции (скримеры, побег из аттракциона) — готовый контент для TikTok/Shorts, как краденые брейнроты были для Steal a Brainrot.

# 2. Две роли игрока
Каждый игрок может играть в обеих ролях — это удваивает контент без удвоения разработки:
1. **Владелец парка** — строит аттракционы, фьюзит и расставляет монстров, зарабатывает на посетителях.
2. **Посетитель** — заходит в чужие парки, проходит их как хоррор-квест, зарабатывает «смелость» (валюту) за прохождение без побега.

> ⚖️ Баланс интересов: владелец хочет напугать (не убить!), посетитель хочет пройти. Обе стороны получают награду за участие — ни одна сессия не «впустую» (принцип Supercell).

# 3. Основной цикл (5–15 минут)
1. Собрать доход с аттракционов (генерируется офлайн, как урожай в Grow a Garden).
2. Купить монстра из ротации магазина (**обновляется каждые 5 минут** — причина не выходить).
3. Поставить 4 монстров в **Фьюжн-машину** → таймер → новый монстр более высокой редкости.
4. Расставить монстров по аттракционам, настроить точки скримеров.
5. Принять волну посетителей → получить доход и очки страшности.
6. Сходить посетителем в чужой парк, пока крутится таймер фьюжна.

## Фьюжн-машина

| Доминантная редкость | Таймер | Комментарий |
| --- | --- | --- |
| Common / Rare / Epic | 10 мин | удержание внутри сессии |
| Legendary / Mythic | 30 мин | причина перезайти |
| Nightmare / Secret | 2 часа | «загадал на ночь — проверил утром» |

- Машина усредняет редкость 4 монстров и определяет доминантную редкость результата (модель Steal a Brainrot).
- Шанс **мутации** результата: Neon ×1.5, Shadow ×3, Blood Moon ×6, Rainbow ×10 к доходу и очкам страха.
- Секретные рецепты: конкретные комбинации монстров дают уникальных боссов (комьюнити само составит вики и гайды — бесплатный маркетинг).

## Ростер монстров на запуск (15 базовых + фьюжн-эксклюзивы)
Стиль: **мультяшный хоррор** (как Doors / Rainbow Friends) — проходит модерацию Roblox, дёшев в производстве, мемогеничен. Главный принцип: у каждого монстра **своя механика испуга**, а не просто модель со звуком.

| Монстр | Редкость | Фишка испуга |
| --- | --- | --- |
| Бу-Шарик | Common | шарик-призрак, летает за посетителем и лопается со скримером |
| Скелет-Стажёр | Common | неуклюже гремит костями, роняет собственный череп (комичный) |
| Крыса в Пальто | Common | притворяется NPC-посетителем и молча идёт следом |
| Желешка | Common | падает с потолка, «заляпывает» экран на 2 секунды |
| Мим Молчун | Common | двигается только когда посетитель отворачивается |
| Клоун Хихик | Rare | смех приближается из темноты раньше самого клоуна |
| Гном-Сталкер | Rare | садовый гном, телепортируется по комнате при каждом моргании света |
| Манекен Мэнни | Rare | стоит в группе обычных манекенов — не угадаешь, который живой |
| Тень-Прыгун | Rare | гасит свет в комнате за секунду до прыжка |
| Бабушка с Пирожками | Epic | «добрая» приманка: взял пирожок — получил скример |

| Хозяин Карусели | Mythic | босс-аттракцион: карусель ускоряется, управление в реверс |

- **Nightmare/Secret — только через фьюжн-рецепты:** например «Симфония Криков» (Дирижёр Тьмы + 3 Epic) или «АнтиМим» (4 Мима Молчуна). Рецепты не публикуются — комьюнити ищет само.
- Самые виральные механики — персонализированные (двойник, шёпот ника): именно их клипят в TikTok.

# 4. Механика испуга (ядро хоррора)
- У посетителя есть шкала **храбрости**. Скримеры, темнота, звуки и монстры её снижают.
- Шкала упала до нуля → посетитель «сбежал» (телепорт к выходу с забавной анимацией паники) → владелец получает максимум очков.
- Посетитель прошёл до конца → получает «смелость» и трофей парка.
- **Очки страшности парка** считаются от реакций реальных игроков → нельзя накрутить ботами AFK.
- Реплеи лучших испугов сохраняются в галерее парка (кнопка «поделиться» — виральность).

## Защита новичков и матчмейкинг
Проблема: новичок в парке ветерана сбегает на первом же скримере. Решения (работают вместе):
1. **Матчмейкинг по тирам:** кнопка «Посетить парк» матчит только в парки своего диапазона (±1 тир страшности). В Nightmare-парк новичок не попадёт случайно.
2. **Урон храбрости — в процентах, а не в абсолютных числах:** скример снимает % от максимума храбрости, а прокачка «смелости» даёт сопротивление и ускоряет восстановление. Новичку и ветерану одинаково честно.
3. **Владельцу невыгодно пугать слабых:** испуг посетителя сильно ниже своего тира даёт ×0.1 очков или 0 — рейтинг растёт только ��а «равных».
4. **Побег ≠ пустая сессия:** сбежавший получает «смелость» пропорционально пройденной дистанции + чекпоинты внутри аттракциона (после побега продолжаешь с середины). Анимация паники — забавная, поражение = мем, а не унижение.
5. **Экскурсионный режим (первые 3–5 визитов):** храбрость не падает ниже 10%, награды снижены, зато новичок видит крутые парки топов — реклама эндгейма «хочу такой же».
Это та же логика, по которой Brawl Stars не пускает в Ranked без бравлера высокого Power Level: игра сначала убеждается, что ты выдержишь уровень соперников.

## Кража (перенос механики steal)
- Раз в N часов можно попытаться **переманить** монстра из чужого парка: мини-стелс-миссия «пройди аттракцион, не испугавшись, и уведи монстра».
- Владелец получает уведомление и может помешать (ловушки, свет).
- Монстров с престижем (см. ниже) переманить нельзя — эмоциональная защита прогресса.

# 5. Supercell-слой (мета-прогрессия)

## 5.1 Ранговая лестница парка
8 тиров × 3 ступени. Очки ранга — за испуги, защиту от переманивания, победы в ивентах.

| Тир | Очков за ступень | Награда за вход в тир |
| --- | --- | --- |
| Bronze | 250 | декор |
| Silver | 250 | монстр Rare |
| Gold | 400 | слот аттракциона |
| Diamond | 500 | эксклюзивный скин ворот |
| Mythic | 600 | монстр Legendary |
| Legendary | 750 | аура парка на карте |
| Masters | 1000 | титул + рамка |
| Nightmare (топ) | без ступеней | глобальный лидерборд |

- **Rank lock:** пересёк мажорный тир — ниже него в этом сезоне не упадёшь (защита от фрустрации, критично для детской аудитории).
- Ранг виден всем: значок над воротами парка и над ником.

## 5.2 Сезоны (4 недели)
- Каждый сезон — новая тема ужасов: Цирк, Глубины, Больница, Космос… Новые монстры, декор, секретные рецепты.
- **Мягкий сброс:** −6 ступеней от пика сезона (не в ноль!).
- **Scare Boost:** первую неделю сезона очки ранга идут ×2–×3 в зависимости от пикового ранга прошлого сезона → быстрый и приятный возврат к своему уровню.
- Награда финала сезона: эксклюзивный сезонный монстр за достигнутый ранг (никогда не возвращается — FOMO, но честный: получают все, кто играл).

### Сезонные монстры и контролируемый пауэр-крип
- Каждый сезон добавляет **10–15 монстров** в теме сезона (Цирк: Акробат-Паук, Фокусник Без Лица, Сиамские Жонглёры…).
- **Правило крипа:** топ-монстр прошлого сезона ≈ уровень топ-3/4 нового сезона. Новый топ сильнее прежнего на ~10% по очкам страха — сдвиг ровно на одну «ступень силы» за сезон.

| Сезон | Топ сезона | Куда сместился прошлый топ |
| --- | --- | --- |
| S1 «Цирк» | Хозяин Карусели | — |
| S2 «Глубины» | Левиафан-Удильщик | Хозяин Карусели → #3–4 |
| S3 «Больница» | Доктор Тишина | Левиафан → #3–4, Карусель → #6–8 |

- **Зачем так:** коллекция ветерана не обесценивается в ноль (плавное смещение, не обрыв), но погоня за новым топом не заканчивается — ровно как выход новых бравлеров в Brawl Stars.
- **Компенсатор крипа:** Prime-звёзды престижа дают +2% к очкам страха за звезду — любимый монстр трёх сезонов остаётся конкурентным.
- ⚠️ Крип больше ~15% за сезон игроки читают как «обесценили мои покупки» — красная линия.

## 5.3 Scare Pass (пропуск)
- Сезонный трек наград, XP за **любую** активность: испуги, прохождения чужих парков, фьюжны, защита.
- Бесплатная ветка щедрая; платная — косметика и ускорители, **без прямой силы** (не pay-to-win).

## 5.4 Престиж монстров (модель Brawl Stars 2026)
- Монстр накапливает «легенду»: испуги, пережитые попытки кражи, участие в фьюжнах потомков.
- Каждые 1000 очков легенды → **Prime-звезда** (Prime 1, 2, 3…): визуальная эволюция (аура, корона, огонь), рост дохода, иммунитет к переманиванию.
- Легенда не сгорает при сезонном сбросе — бесконечная накопительная прогрессия без потолка.
- Дилемма фьюжна: сжечь престижного любимца ради шанса на редкость — сильное эмоциональное решение.

## 6.2 Первая покупка: оффер «Первый Испуг» за 5 R$
- **Содержимое:** ×2 доход на 24 часа + эксклюзивный скин монстра + 1 бесплатное ускорение фьюжна. Визуальная ценность ~50 R$ → подаётся как «скидка 90%».
- **Когда показывать:** после первого вау-момента (первый успешный фьюжн, ~15–20 минут игры), а НЕ при входе — оффер на входе игнорируется.
- **Цель — не заработать, а конвертировать:** игрок, заплативший хотя бы раз, многократно чаще платит снова. Целевая конверсия в первую покупку: ≥3–5% игроков.
- **Лестница платежей после первой покупки:** следующие офферы 25 R$ → 99 R$ → 399 R$ (Scare Pass) с нарастающей ценностью.

# 9. Риски
1. **Хоррор слишком страшный для модерации Roblox** → стиль «мультяшный ужас» (как Doors), рейтинг Mild.
2. **Владельцы делают непроход��мые парки** → очки только за испуг *проходимых* посетителей: сбежавшие до середины дают 0.
3. **Тренд тайкунов остынет** → ядро (fusion + социальный хоррор) переносимо на новую обёртку сезонами.
4. **Одиночество на старте (мало посетителей)** → NPC-посетители как заглушка до набора онлайна, но с пониженными очками.

# 10. Продакшн: плейс, серверы, модели

## 10.1 Плейс и серверы
- **Один сервер = 8 игроков** (как в Steal a Brainrot): достаточно посетителей друг для друга, терпимо по производительности.
- Карта: центральная площадь-хаб (магазин с ротацией, витрина фьюжн-рецептов, лидерборды, портал «Посетить парк») + 8 участков-парков по кругу.
- Участок: стартово 3 слота аттракционов → расширение до 8–10 (гринд или gamepass).
- **StreamingEnabled обязателен** — парки подгружаются частями, иначе 8 застроенных парков положат слабые телефоны (основная аудитория — мобилки).
- Матчмейкинг по тирам решается телепортом между серверами (TeleportService + MemoryStore для подбора).

## 10.2 Откуда брать модели монстров

| Способ | Цена | Когда использовать |
| --- | --- | --- |
| Blender + Roblox Studio | бесплатно | основной пайплайн; лоу-поли мультяшный стиль прощает простые модели |
| AI-генерация 3D (Meshy, Tripo3D) → доработка в Blender | 0–20 $/мес | быстрые черновики и поиск форм; для финала дорабатывать руками |
| Roblox Creator Store (бесплатные ассеты) | бесплатно | пропсы, декор, звуки — но НЕ ключевые монстры (теряется уникальность) |
| Заказ у моделлеров (Roblox Talent Hub, Fiverr) | $10–40 за лоу-поли модель | 15 базовых монстров ≈ $200–500, если нет времени учить Blender |
| Анимации: Moon Animator 2 или Mixamo | бесплатно / ~$40 | Mixamo — готовые анимации для гуманоидных ригов |

## 10.3 Пайплайн одного монстра
1. Концепт: референсы + читаемый силуэт (монстра должно быть видно издалека).
2. Модель в Blender, до 5–10k полигонов.
3. Простые текстуры/градиенты — стиль важнее детализации.
4. Риг + 3 анимации: idle, скример, погоня.
5. Звук скримера: Freesound / Pixabay (лицензия CC0). **Звук — это 60% испуга**, вкладываться в аудио дешевле и эффективнее, чем в модели.
6. Импорт в Studio, скрипт поведения (своя механика испуга из ростера).
План производства: 2–3 монстра в неделю силами одного человека → 15 базовых за 5–7 недель, параллельно с кодом MVP.
