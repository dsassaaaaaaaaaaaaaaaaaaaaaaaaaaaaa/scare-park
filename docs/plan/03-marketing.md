# 📣 Маркетинг — инструкция

# 💸 Монетизация трафика: Audience Expansion (v2)
Roblox платит **35% от покупок Robux** новых и вернувшихся (60+ дней неактивности) игроков первые 2 месяца, если они пришли через нашу игру (программа Creator Rewards).
- Все внешние ссылки (TikTok, Shorts, Discord, YouTube) ведут строго на страницу игры — иначе атрибуция теряется.
- Кампании «вернись в новый сезон» работают под этот же механизм: вернувшийся игрок тоже засчитывается.
- Виральный маркетинг из статьи расходов превращается в источник дохода — KPI: ≥3% выручки от Audience Expansion.

# Встроенная виральность (делается в игре, а не в соцсетях)
1. **Кнопка «поделиться испугом»** в галерее реплеев — готовый вертикальный клип.
2. Персонализированные испуги (шёпот ника, двойник аватара) — такое клипят чаще всего.
3. Секретные рецепты без публикации → комьюнити снимает гайды и строит вики — бесплатный контент-маркетинг.
4. Редкие события-зрелища: Blood Moon раз в несколько часов (все мутации ×2) — причина стримить и звать друзей ПРЯМО СЕЙЧАС.

# Страница игры (ASO внутри Roblox)
- Название: короткое + эмодзи + текущий ивент: «🎢 Scare Park 👻 [ЦИРК!]». Обновлять тег каждый сезон.
- Иконка: один монстр крупным планом + эмоция. Тестировать 2–3 варианта через встроенные A/B тесты иконок Roblox.
- Тамбнейлы: первый — геймплейная сцена испуга, второй — коллекция монстров, третий — ранговая лестница.

# Ритм релизов
- Обновление каждую неделю–две, всегда в одно время (например пятница вечер) — игроки привыкают ждать.
- За 2–3 дня до обновления — тизер силуэта нового монстра в Discord/TikTok.
- Каждое обновление = повод для ролика и пуш-уведомления подписчикам группы.

# 🚫 Правила (жёсткие «нельзя»)
1. Нельзя кликбейтить несуществующим контентом: игрок пришёл — не нашёл — дизлайк → алгоритм Roblox хоронит игру (рейтинг <85% = смерть рекомендаций).
2. Нельзя покупать ботов/накрутку — бан игры и аккаунта.
3. Нельзя лить платный трафик до удержания D1 ≥ 25% — сначала чиним воронку, потом масштабируем.
4. Нельзя обещать даты релизов публично — только «скоро» и тизеры. Сорванная дата = волна негатива.
5. Нельзя игнорировать правила рекламы Roblox для детской аудитории (никаких «купи сейчас» в креативах, таргетинг <13 ограничен).

# ✅ Рекомендации
1. Первые 2 недели после релиза — отвечать на КАЖДЫЙ комментарий в TikTok — алгоритм любит вовлечённость, а дети — внимание разработчика.
2. Давать инфлюенсерам именные коды (награда обоим: зрителю и каналу статистика) — так видно, кто реально приводит игроков.
3. Снимать ролики на английском или без слов (только геймплей + музыка) — глобальный охват вместо одного рынка. Русскоязычный сегмент — наше преимущество (дешёвый CPM, мало конкурентов), но экономика строится на глобальном миксе: цель ≥40% US/EU-трафика; игра мультиязычна с первого дня (EN базовый, RU, PT-BR, ES) (v2).
4. Лучший контент — чужой: репостить клипы игроков, сделать в Discord канал #клипы с наградой «клип недели».
5. Запускать игру тихо (soft launch): 1–2 недели без рекламы, чиним метрики по первым игрокам, ПОТОМ инфлюенсеры.
6. Сезонные темы планировать под реальные события: хэллоуинский сезон — пик года для хоррор-игры, готовить заранее.
