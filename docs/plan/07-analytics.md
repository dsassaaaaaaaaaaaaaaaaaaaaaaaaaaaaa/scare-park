# 📊 Аналитика и метрики — инструкция

> 🎯 Цель: каждое решение по балансу, контенту и ценам принимается по данным, а не по ощущениям. Аналитика закладывается С ПЕРВОГО ДНЯ — задним числом данные не собрать.

# События для логирования (минимальный набор)

| Событие | Зачем |
| --- | --- |
| session_start / session_end | DAU, длина сессии |
| tutorial_step (1–5) | где отваливаются новички |
| fusion_start / fusion_complete | вовлечённость в ядро |
| scare / escape / visit_complete | баланс испуга (доля побегов по тирам) |
| offer_shown / offer_bought | конверсия каждого оффера |
| rank_up / season_return | работа мета-слоя |
| sub_start / sub_renew / sub_cancel | здоровье VIP-подписки (v2) |
| gift_sent / troll_item_used | социальные покупки: гифтинг и троллинг-магазин (v2) |
| first_game_of_day | доля игроков, стартующих день с нас (Creator Rewards, v2) |

# Две главные воронки
1. **Онбординг:** вошёл → получил монстра → первый испуг → первый фьюжн → вернулся на день 2. Падение >30% на любом шаге = приоритетная задача недели.
2. **Монетизация:** оффер показан → открыт → куплен → повторная покупка в 30 дней.

# Еженедельный дашборд (30 минут каждые выходные)
- DAU и визиты, динамика к прошлой неделе
- D1 / D7 retention
- Средняя длина сессии
- Конверсия в первую покупку, выручка на 1000 визитов
- Доля рекуррентной выручки и retention VIP-подписки (v2)
- Доля спендеров, стартующих день с нашей игры + доход Creator Rewards (v2)
- Рейтинг игры (лайки) и топ жалоб
- Доля побегов новичков (здоровье матчмейкинга: если новички сбегают >80% визитов — защита не работает)

# Главная метрика по этапам

| Этап | Одна главная метрика |
| --- | --- |
| MVP / soft launch | D1 retention (≥ 25% до запуска рекламы) |
| Рост | D7 retention и доля из рекомендаций |
| Монетизация | конверсия в первую покупку |
| Зрелость | возврат в первую неделю сезона |

# 🚫 Правила (жёсткие «нельзя»)
1. Нельзя менять несколько вещей одновременно перед замером — не поймёшь, что сработало.
2. Нельзя смотреть только средние: всегда разбивать на сегменты — новички/ветераны, платящие/F2P, телефон/ПК.
3. Нельзя принимать решения по 1–2 дням данных — минимум неделя (выходные искажают картину).
4. Нельзя оптимизировать метрику во вред игроку (например, растягивать сессию искусственными задержками) — краткосрочный рост, долгосрочный отток.

# ✅ Рекомендации
1. Одна главная метрика на этап — все остальные только наблюдаются.
2. Когортный анализ: сравнивать игроков, пришедших в разные недели — так видно, улучшают ли обновления игру на самом деле.
3. Следить за «кладбищем прогресса»: на каком ранге/редкости игроки массово бросают — там дыра в балансе.
4. Раз в месяц самому проходить путь новичка с нового аккаунта — цифры не показывают то, что чувствует игрок.
