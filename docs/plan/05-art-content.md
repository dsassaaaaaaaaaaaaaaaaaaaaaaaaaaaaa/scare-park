# 🎨 Арт и контент — инструкция

> 🎯 Цель: единый узнаваемый стиль «мультяшный хоррор», который дёшев в производстве, проходит модерацию Roblox и работает на слабых телефонах.

# Стайлгайд
- **Стиль:** лоу-поли, мультяшные пропорции (большая голова/глаза), жуткое через позу и свет, а не через кровь. Референсы: Doors, Rainbow Friends.
- **Палитра:** тёмные сине-фиолетовые фоны + 1–2 неоновых акцента на монстре (глаза, пасть, аура мутации).
- **Силуэт-тест:** монстр узнаваем по чёрному силуэту без текстур. Не прошёл тест — переделывать форму, а не текстуру.
- **Мутации** (Neon/Shadow/Blood Moon/Rainbow) — шейдер/материал поверх базовой модели, а не отдельная модель — 1 модель = 5 вариантов бесплатно.

# Чеклист готовности монстра
- [ ] Силуэт-тест пройден
- [ ] ≤ 10k полигонов, 1–2 материала
- [ ] 3 анимации: idle, скример, погоня
- [ ] Звук скримера нормализован (не громче остальных — беречь уши и рейтинг)
- [ ] Скример работает на слабом телефоне без фризов
- [ ] Механика испуга уникальна (не копия уже существующего монстра)
- [ ] Проверен на соответствие рейтингу Mild

# Контент-календарь сезона (4 недели)

| Неделя до старта | Что готово |
| --- | --- |
| −4 | тема сезона, список 10–15 монстров, концепты |
| −3 | топ-3 монстра смоделены (их покажем в тизерах) |
| −2 | весь ростер + декор-сет + скины пасса |
| −1 | всё в игре на тестовом плейсе, тизеры выходят |

# UI
- Кнопки крупные под большой палец — аудитория на телефонах.
- Максимум 2 шрифта; цвета редкостей едины везде (магазин, инвентарь, таблицы).
- Главный экран показывает 4 счётчика прогресса без лишних кликов: ранг, пасс, таймер фьюжна, легенда.

# 🚫 Правила (жёсткие «нельзя»)
1. Нельзя реалистичную кровь, расчленёнку, реалистичный гор — модерация Roblox + потеря детской аудитории.
2. Нельзя использовать чужие IP: персонажи из фильмов/игр, брендовые брейнрот-мемы с авторскими правами — риск удаления игры.
3. Нельзя брать ассеты без понятной лицензии (звуки, модели) — только CC0/своё/купленное.
4. Нельзя делать ключевых монстров из бесплатных ассетов Creator Store — игра теряет лицо, а клоны получают таких же.
5. Нельзя перегружать сцену партиклами и динамическим светом — FPS на мобилках важнее красоты.

# ✅ Рекомендации
1. Звук решает 60% испуга: вкладываться в аудио (нарастающий эмбиент, тишина перед скримером) дешевле и эффективнее, чем в модели.
2. Переиспользовать риги: один гуманоидный + один «ползучий» риг покрывают 80% монстров.
3. Сначала серый бокс и механика, потом арт: не заказывать модель, пока испуг не веселит в прототипе.
4. Тестировать «страшность» на реальных детях (младшие братья/сёстры, друзья): цель — визг и смех, а не слёзы.
5. Вести единый реестр ассетов (таблица: монстр, статус, источник, лицензия) — чтобы не потерять, что откуда взято.
