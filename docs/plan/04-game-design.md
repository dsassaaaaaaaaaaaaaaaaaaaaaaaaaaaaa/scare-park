# 🎮 Гейм-дизайн и баланс — инструкция

> 🎯 Цель: каждая сессия любой длины должна заканчиваться видимым прогрессом хотя бы по одному из четырёх счётчиков: ранг · пасс · фьюжн · легенда монстров.

# Три петли удержания

| Петля | Горизонт | Механика |
| --- | --- | --- |
| Короткая | 1–5 мин | сбор дохода, ротация магазина, один испуг |
| Средняя | 10–40 мин | фьюжн-таймер, волна посетителей, поход в чужой парк |
| Длинная | дни/недели | ранговая лестница, сезон, пасс, Prime-звёзды |

# Онбординг: первые 10 минут (самое важное в игре)
1. 0–1 мин: игрок СРАЗУ получает участок + первого монстра бесплатно. Никаких длинных туториалов.
2. 1–3 мин: первый посетитель (NPC) пугается его монстра → первые монеты + конфетти. **Вау-момент до 3-й минуты.**
3. 3–7 мин: покупка ещё 3 монстров → первый фьюжн (ускоренный таймер 1 мин для первого раза).
4. 7–10 мин: приглашение сходить в чужой парк (экскурсионный режим) → видит эндгейм.
5. После первого фьюжна — оффер «Первый Испуг» 5 R$ (см. бизнес-часть).

# Баланс: опорные числа (v1, править по данным)

| Параметр | Значение |
| --- | --- |
| Доход монстра/мин: Common | 1 |
| Rare | 3 (×3) |
| Epic | 9 |
| Legendary | 27 |
| Mythic | 81 |
| Nightmare/Secret | 243+ |
| Офлайн-доход | 50% от онлайна, кап 8 часов |
| Скример: урон храбрости | 15–35% от максимума (по редкости монстра) |
| Кулдаун скримера одного монстра | 20–30 сек |
| Восстановление храбрости | 2%/сек в «безопасных зонах» между комнатами |
| Правило цен магазина | монстр окупается за ~30–45 мин активной игры |

Формула очков страха за посетителя: base × множитель редкости × множитель мутации × модификатор разницы тиров (0.1 → 1.5). Побег посетителя даёт владельцу 100% очков, полное прохождение без побега — 25% (парк всё равно «работал», ни одна волна не впустую).

# 🚫 Правила (жёсткие «нельзя»)
1. Нельзя ругать игрока за пропуски: стрики восстанавливаются, ежедневные награды можно догнать, прогресс не сгорает.
2. Нельзя отнимать заработанное: любое поражение = меньше награда, но никогда не минус (исключение — очки ранга выше rank lock, это честная соревновательная зона).
3. Нельзя таймеры длиннее 8 часов и больше 2 параллельных «ожиданий» одновременно — иначе игра превращается в «зайди завтра».
4. Нельзя делать скрытые нерфы: любое изменение баланса — в патчноуте. Комьюнити всё равно заметит, но со скрытым нерфом потеряет доверие.
5. Нельзя награждать за чистое время онлайна — плодит AFK-фермы и вредит детям. Награждать только действия.
6. Нельзя добавлять механику, которая не двигает ни один из 4 счётчиков прогресса — это балласт.
7. Нельзя пугать «нечестно»: скример без телеграфа (звук/свет за долю секунды) ощущается как обман, а не как страх.

# ✅ Рекомендации
1. Pity-система: гарантированная повышенная редкость после N неудачных фьюжнов подряд — убирает чувство «меня обманывают».
2. Заканчивать сессию крючком: перед выходом показывать экран «через 30 мин готов фьюжн · до следующей ступени 120 очков».
3. Праздновать чужой успех публично: весь сервер видит чей-то Nightmare-фьюжн — зависть как мотивация.
4. Прототипировать испуги в «сером боксе» (кубы вместо моделей) до заказа арта — механика важнее картинки.
5. Балансить по данным, а не по ощущениям: еженедельно смотреть, на каком этапе прогрессии игроки застревают и уходят (см. ветку Аналитика).
6. Первую неделю после релиза держать экономику щедрее расчётной (+20–30% дохода) — лучше потом аккуратно подкрутить вниз для НОВЫХ игроков, чем отпугнуть первую волну жадностью.
